# Single-Agent vs Multi-Agent Comparison

## Phương pháp
Dùng cùng một bộ câu hỏi kho, cùng database và cùng model.

Đo 3 tiêu chí bắt buộc:
- Accuracy: câu trả lời có bám dữ liệu và đúng claim không.
- Response time: thời gian từ request tới response.
- LLM calls: số lần gọi Gemini.
