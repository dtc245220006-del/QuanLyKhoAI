# Question Analysis Skill — QuanLyKhoAI

## Quy tắc
- Câu hỏi phải được chuyển thành intent có cấu trúc.
- Không tự tạo hàng hóa, giá hay tồn kho.
- Khi câu hỏi liên quan tồn kho, ưu tiên dữ liệu HangHoa + TonKho.
- Giữ đúng tên hàng hóa và các điều kiện mà người dùng nêu.
